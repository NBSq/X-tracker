# Code of Conduct

## Our Standard

We want participation in `x-narrative-tracker` to be respectful, technically constructive, and welcoming. Good contributions assume good intent, critique ideas rather than people, respect privacy, and make room for different experience levels and perspectives.

Harassment, threats, discriminatory language, sexualized attention, deliberate disruption, doxxing, and publishing another person's private information are not acceptable.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions, and other project spaces, as well as when someone publicly represents the project.

## Reporting And Enforcement

Report conduct concerns privately to the repository maintainer. Do not use a public issue when doing so would expose a target or sensitive details. Maintainers may edit or remove content, reject contributions, issue warnings, or temporarily or permanently restrict participation based on the severity and pattern of behavior.

Reports will be handled as confidentially as practical. Retaliation against a reporter is itself a violation.
